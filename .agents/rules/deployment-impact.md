# What a change owes the deployment

When a change touches one of the rows below, update what is listed in the same commit. Paths under `templates/` and `values*.yaml` are in the chart, `deploy/helm/pachanguero`.

Then run `helm lint deploy/helm/pachanguero -f deploy/helm/pachanguero/values.secrets.yaml.example` and `helm template pachanguero deploy/helm/pachanguero -f deploy/helm/pachanguero/values.secrets.yaml.example > /dev/null`.

Unsure whether a change is deployment-relevant: grep the chart and the `Dockerfile` for the old name. Keep the settings row and [`deployment-settings.test.ts`](../../server/src/deployment-settings.test.ts) in step ([test strategy](../../docs/test-strategy.md#deployment-settings-test)).

Not needed for a pin move done through `skill: pachanguero-3pp-update`.

| Change                                                                                                                                         | Also update                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| ---------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| A setting (environment variable) added, renamed or removed, or a new default                                                                   | `.env.example`; the settings table in `docs/commands.md`; if the operator may set it in production, a value in `values.yaml` and an `env:` entry in `templates/deployment.yaml`; if the container needs a default, the `Dockerfile` `ENV` and the line listing the image's defaults in the `## Container` section of `docs/commands.md`                                                                                                                                                                                                                                     |
| A new secret                                                                                                                                   | `templates/secret.yaml`, the `secrets:` block in `values.yaml`, `values.secrets.yaml.example`, and the operator's own `values.secrets.yaml` (tell the user)                                                                                                                                                                                                                                                                                                                                                                                                                 |
| Port, listen address, health-check path, or the `/data` and `/backups` volumes                                                                 | `Dockerfile` (`PORT`, `EXPOSE`, `HOST`); `containerPort` and both probes in `templates/deployment.yaml`; `port` in `templates/service.yaml`; the `/data` and `/backups` mounts of the app and backup containers; the staging `hostPath` (`backup.stagingPath`)                                                                                                                                                                                                                                                                                                              |
| `pachanguero-admin backup`, backup file names or folder                                                                                        | `server/src/domain/backup-name.ts` and its test (which holds the pattern); `server/src/db/database-backup.test.ts`; `scripts/verify-release.sh` (hardcodes the `erebor` context and namespace); `scripts/prod-copy.sh` (takes the newest `periodic_*.db` or `release_*.db` and reads the command's `✓` line); `docs/commands.md`, `.env.example`, `docs/backup_and_restore.md`, `docs/deployment.md#data-and-backups`; the release, deployment-management and production-copy skills (they quote the names); the `backup.stagingPath` `hostPath` and the folder on `erebor` |
| The same change, outside this repository (tell the user)                                                                                       | the shipper's accepted name pattern (`NAME_RE` in `trade4me-server`'s `backup-shipper` chart, `files/push-backups.sh`) and its staging folder: a name it does not match is never shipped, silently; `home-network-map` (`services/pachanguero`, `services/backup-shipper`)                                                                                                                                                                                                                                                                                                  |
| A new workspace, a changed `dist` layout or entry point, the `pachanguero-admin` command name, or the container user                           | `Dockerfile` (the `COPY …/package.json` lines, `CMD`, the admin wrapper, `USER`); for the user, `securityContext` in `templates/deployment.yaml`                                                                                                                                                                                                                                                                                                                                                                                                                            |
| Node version or a native dependency                                                                                                            | the single `NODE_IMAGE` pin of the `Dockerfile` and `.nvmrc`; the `@types/node` major; the backup sidecar runs the same image and needs GNU `date` and the `Europe/Madrid` zone data; `skill: pachanguero-3pp-update` moves these, with the exact `jose` and `@dnd-kit/core` pins and the npm dependencies                                                                                                                                                                                                                                                                  |
| The version the app reports (`PACHANGUERO_VERSION`, set in `templates/deployment.yaml` for both containers from the image tag or `appVersion`) | the backup names carry it; `.env.example`, the settings table in `docs/commands.md`, `scripts/verify-release.sh deployed`, `scripts/bump-version.sh`                                                                                                                                                                                                                                                                                                                                                                                                                        |
| The registry, host, namespace, NodePort, pod label or container names                                                                          | `build.sh`, `deploy/deploy.sh`, `values.yaml`, `docs/deployment.md`, `scripts/prod-copy.sh`, and the `--context`/`-n` lines of the two skills in `ai-kit/skills/`                                                                                                                                                                                                                                                                                                                                                                                                           |
