# Decisions

Procedure for an item whose target is a choice.

1. Present the user the alternatives, each with pros, cons and your recommendation.
2. Wait for the choice.
3. Show the entry.
4. Write it in `.3pp-management.md`, in the same commit as the update. Use the user's
   reason; never invent one.
5. Entry: a `##` heading with the item and the decision; `Since <date>`; the reason; the
   alternatives rejected; `Lifts when:` a command in backticks and the result that ends the
   decision, only if it can end.
